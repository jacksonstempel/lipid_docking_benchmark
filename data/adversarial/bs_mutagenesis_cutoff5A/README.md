# Archived Adversarial Mutagenesis Summaries

This directory contains the minimal archived CSVs needed to regenerate the
manuscript adversarial mutagenesis figure without shipping the full local
`output/` workspace.

Included:

- `benchmark_gly/benchmark_summary.csv`
- `benchmark_phe/benchmark_summary.csv`
- `mutation_summary.csv`

Not included:

- full mutant all-pose CSVs
- raw Boltz mutant prediction directories
- local scratch analysis outputs

The analysis scripts prefer this tracked archive automatically when it is present.
