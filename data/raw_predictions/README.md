# Raw Prediction Outputs

Canonical raw prediction outputs that complement the benchmark-result tables in
`data/reproducibility/`.

Contents:

- `gnina/`
  - GNINA CNN-rescored and no-CNN raw runs
  - per-target logs
  - pair manifests for benchmarking those runs directly
- `adversarial/`
  - binding-site mutagenesis Boltz inputs and raw outputs
  - pair manifests for benchmarking those runs directly
  - mutation bookkeeping

Integrity:

- `SHA256SUMS.txt` records the file hashes for this raw-prediction bundle.
