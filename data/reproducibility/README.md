# Tracked Manuscript Archive

This directory contains the benchmark-result tables needed to reproduce the
published manuscript analysis bundle.

It is the canonical public data source for:

- the unified SQLite database built by `scripts/build_benchmark_db.py`
- the manuscript figures regenerated by `scripts/analyze_benchmark_db.py`
- the robustness checks verified by `scripts/verify_manuscript_numbers.py`

Contents:

- `baseline/`: baseline Boltz + Vina benchmark tables
- `gnina/`: GNINA CNN and no-CNN all-pose tables
- `adversarial/`: adversarial mutagenesis all-pose tables, summary tables, and mutation bookkeeping
- `robustness/`: Vina exhaustiveness-256 and higher-sampling Boltz-2 reruns

These files are versioned as public source data for the manuscript companion.
They are not generated during CI and should not be replaced by ad hoc local
outputs without an intentional update to the public archive.

Checksums for the tracked archive files are recorded in `SHA256SUMS.txt`.
