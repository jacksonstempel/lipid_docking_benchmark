# Data Layout

This repository uses two distinct data locations.

## Tracked public archive

`data/reproducibility/` is the tracked manuscript archive. It contains the small
benchmark-result tables needed to reproduce the published analysis bundle.

Nothing under `data/reproducibility/` is generated by CI or local reruns; it is
treated as versioned source data for the public manuscript companion.

## Local generated outputs

Everything generated by reruns or analysis belongs under `output/`.

Recommended structure:

- `output/benchmark/`
  - `benchmark_allposes.csv`
  - `benchmark_summary.csv`
  - `benchmark_full.sqlite`
- `output/analysis/db_pipeline/`
  - `per_target.csv`
  - `summary_table_numeric.csv`
  - `summary_table_formatted.csv`
  - `torsion_table_numeric.csv`
  - `torsion_table_formatted.csv`
- `output/gnina/`
  - local GNINA run directories or exploratory analyses
- `output/adversarial/`
  - local adversarial experiment workspaces

The public repo does not track `output/`.
